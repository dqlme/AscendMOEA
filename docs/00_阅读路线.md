## 文档采用的视角

本文档把平台拆成四条相互独立的路径：

1. **求解路径**：算法、问题、工作流和最终种群。
2. **扩展路径**：注册表、基类、公开算子和用户模块。
3. **实验路径**：随机种子、设备同步、历史种群、指标与资源记录。
4. **工程路径**：环境、测试、批量调度、诊断和发布。

这样组织的目的是让使用者可以从具体任务切入，不要求先理解完整框架。

## 版本约定

本文档对应 AscendMOEA `0.1.0`。代码块默认使用 Python 3.9 以上版本，所有目标均按
最小化问题描述，约束采用 `g(x) <= 0`。涉及正式性能结论时，必须按照第 11 章的同步、
预热、线程和重复实验规则执行，不能用单次交互运行代替基准结果。

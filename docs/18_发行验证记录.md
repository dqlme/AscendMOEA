# AscendMOEA 0.1.0 发行验证记录

## 验证范围

本页记录 0.1.0 发行目录的静态检查、安装包检查、CPU 运行验证和昇腾 NPU 运行验证。
运行验证使用小种群和小评价预算，只判断公开组件能否正确构造、批量计算、迭代、终止和
扩展，不将烟雾测试时间解释为标准规模性能。

| CPU 烟雾线程 | 1 |
| NPU 烟雾设备 | `npu:0` |

## 静态检查

发行目录执行以下检查：

```bash
ruff check --select E,F,I,W .
pytest -q
python tools/validate_release.py --device cpu --cpu-threads 1
python tools/validate_release.py --device npu:0
```

检查范围包括：

- 全部 Python 文件的 Python 3.9 语法兼容性；
- 模块、类和函数的英文 docstring；
- 公开算法、问题、算子、指标和工作流导入；
- 20 个内置算法的最小代际流程；
- 155 个内置问题的批量构造、初始化、目标和约束有限值；
- 19 个公共算子导出名及其形状、dtype、device 和数值门禁；
- 自定义算法、自定义问题及注册表扩展；
- 安装包中的 91 个 MAT 数据资源；
- 源码目录之外的隔离导入。

## 发布门禁

只有同时满足以下条件，目录才标记为可发布：

1. Ruff 和 pytest 通过；
2. CPU 与 NPU 运行验证通过；
3. 20 个算法、155 个问题、公共算子和自定义扩展全部通过；
4. wheel 可在源码目录之外导入并访问全部数据资源；
5. 源码和文档不存在缓存、构建产物、过期名称或失效链接；
6. 源码归档、wheel 和验证报告均保存 SHA-256。

本版本六项技术门禁均已通过。公开分发前仍应按 `NOTICE.md` 核对数据资源的授权范围。

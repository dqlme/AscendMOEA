# Attribution and release scope

AscendMOEA contains independently organized Python and PyTorch implementations
of multi-objective evolutionary methods, benchmark definitions, and engineering
datasets. Implementations are validated with fixed numerical fixtures, device
cross-checks, and repeatable regression suites.

Algorithm contributors, benchmark contributors, and dataset owners retain their
respective rights. A public release must keep applicable attribution metadata
and verify redistribution permission for every bundled dataset. This notice
does not grant rights that a contributor does not own.
